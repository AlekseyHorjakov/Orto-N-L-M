# Архитектура Ортона-AI

Ортона-AI построена как веб-приложение с отдельными слоями интерфейса, серверной логики, хранения данных и AI-автоматизации.

## Схема

```text
React / Vite
     │
     ▼
 FastAPI ───────── n8n ───────── OpenAI API
     │
     ▼
 PostgreSQL
```

## Компоненты

- **React / Vite** — веб-интерфейс и кабинеты руководителя, специалиста и стажёра.
- **FastAPI** — REST API, аутентификация, роли и бизнес-операции.
- **PostgreSQL** — хранение пользователей, должностей, процессов, интервью, файлов и результатов обучения.
- **n8n** — оркестрация AI-сценариев и интеграций.
- **OpenAI API** — обработка диалога и генерация материалов.

## Ключевая модель данных

Process JSON — структурированное описание рабочего процесса и единая основа для производных материалов.

```text
Должность
   ↓
Процесс
   ↓
Process JSON
   ├── Инструкция
   └── Обучение → Тест → Результат
```

## Пользовательские сценарии

1. Специалист проходит AI-интервью и описывает рабочий процесс.
2. Система формирует Process JSON и позволяет подготовить инструкцию.
3. Стажёр изучает материалы и проходит тестирование.
4. Руководитель управляет пользователями и должностями, просматривает результаты обучения.

## Развёртывание

Приложение развёрнуто в production. Используются Docker, Ubuntu Server, Caddy и HTTPS.

## Текущее развитие

Основные пользовательские контуры веб-приложения реализованы и проверены. Подключение корпоративной базы знаний и RAG-поиска — отдельное следующее направление развития.
