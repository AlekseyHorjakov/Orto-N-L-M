# Работа приложения Ортона-AI

Этот документ кратко описывает взаимодействие основных частей продукта.

## Пользовательский путь

```text
Веб-приложение
      ↓
   FastAPI
      ├── PostgreSQL — данные и состояние
      └── n8n / OpenAI — AI-сценарии
                  ↓
             Process JSON
                  ↓
       Инструкция / обучение / тест
```

## Основной сценарий получения знаний

1. Специалист открывает AI-интервью в веб-приложении.
2. Передаёт информацию о рабочем процессе текстом, голосом и иллюстративными материалами.
3. AI помогает уточнить детали и структурировать ответы.
4. Результат сохраняется в виде Process JSON.
5. На основе процесса подготавливается рабочая инструкция.

## Сценарий обучения

1. Стажёр выбирает должность и доступную инструкцию.
2. Изучает материал.
3. Проходит тест, сформированный на основе Process JSON.
4. Результат и прогресс сохраняются.
5. Руководитель может просматривать результаты обучения.

## Роли компонентов

- **React / Vite:** пользовательский интерфейс.
- **FastAPI:** API и серверная логика.
- **PostgreSQL:** постоянное хранение данных.
- **n8n:** оркестрация AI-сценариев.
- **OpenAI API:** обработка диалога и генерация материалов.

## Экспорт workflow

В каталоге `workflows/` находится workflow, связанный с веб-сценариями продукта. Перед импортом или обновлением workflow сверяйте экспорт с рабочей конфигурацией n8n.
