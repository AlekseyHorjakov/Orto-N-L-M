# Менеджерский контур Orto-N-L-M

**Актуальная фиксация:** 4 сентября 2026

## Меню руководителя

Меню содержит только:

- `👤 Должности`
- `📚 Инструкции`

Разделы `Процессы` и `Настройки` в текущем рабочем меню отсутствуют.

## Должности

Руководитель может:

- открыть список должностей;
- добавить должность;
- открыть должность;
- изменить название;
- удалить должность после подтверждения.

При удалении сначала удаляются связанные процессы, затем сама должность. Это необходимо из-за связи `processes.position_id`.

## Инструкции

Сценарий:

```text
Руководитель
   ↓
📚 Инструкции
   ↓
Выберите должность для вывода инструкций.
   ↓
Должность
   ↓
Список инструкций
   ↓
Кнопка инструкции
   ↓
Process JSON из PostgreSQL
   ↓
HTML
   ↓
Telegram
```

Выдача существующей инструкции не использует AI.

## Вложения

В менеджерской ветке `Prepare HTML Attachments` берёт вложения непосредственно из `process_json`. Используются реальные `file_path`, `file_name`, `mime_type` и описание, сохранённые для соответствующего шага.

## Актуальный workflow

Рабочий экспорт: `Orto-N Learning Manager (33).json`.

Публичный GitHub не содержит живой Telegram Bot Token. HTTP Request узлы рабочего экспорта сохраняют свою рабочую логику; секрет остаётся только в окружении n8n.
