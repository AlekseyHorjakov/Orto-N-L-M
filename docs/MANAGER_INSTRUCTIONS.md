# Менеджерский доступ к инструкциям

## Текущий сценарий

Руководитель получает доступ к уже сохранённым рабочим инструкциям через Telegram.

```text
Меню руководителя
    ↓
Список инструкций
    ↓
Выберите должность для вывода инструкций.
    ↓
Кнопка должности
    ↓
Список инструкций выбранной должности
    ↓
Кнопка инструкции
    ↓
Получение канонического Process JSON
    ↓
Формирование HTML-файла
    ↓
Отправка документа в Telegram
```

## Принцип

Получение готовой инструкции руководителем не использует AI.

Канонический источник инструкции — `process_json`, сохранённый в PostgreSQL. AI используется в процессе интервью и формирования знаний, но не нужен для поиска и выдачи уже существующей инструкции.

## Telegram UI

При открытии списка инструкций выводится только:

> Нажмите на инструкцию, чтобы получить её.

Для первого уровня используются динамические inline-кнопки должностей:

> Выберите должность для вывода инструкций.

После выбора должности отображаются только инструкции этой должности. Текстовый дубль названий инструкций в сообщении не выводится — названия находятся непосредственно на кнопках.

## Callback

Для получения конкретной инструкции используется callback вида:

```text
get_instruction:<process_id>
```

`process_id` однозначно определяет сохранённый процесс в базе данных.

## Нормализация должностей

25.08.2026 существующие дубли должностей были объединены без изменения самих процессов. Процессы, связанные с дублями, переведены на основную запись должности.

После нормализации в `positions` осталось 5 уникальных должностей:

- Администратор (`id = 10`)
- Главный специалист по контролю визуальной атмосферы рабочего пространства (`id = 25`)
- Контролер продуктов в холодильнике (`id = 27`)
- Регистратор (`id = 18`)
- Смотритель картинок на рабочем месте (`id = 24`)

Нормализация была выполнена без изменения владельца таблицы и без удаления `positions_name_key`.

## Prepare HTML Attachments

Узел поддерживает два режима:

1. **Обычное создание инструкции после интервью** — используется `Instruction Generator`, `Get Saved Process` и материалы интервью.
2. **Выдача готовой инструкции руководителю** — используется `Get Instruction` и непосредственно `process_json` из базы.

В менеджерском режиме вложения берутся из `process_json` и их `file_path`; AI для этого режима не используется.
