# Кабинет руководителя Ортона-AI

Кабинет руководителя предназначен для управления организационной структурой, пользователями, инструкциями и контроля обучения.

## Основные разделы

- **Должности** — просмотр, создание, редактирование и удаление должностей.
- **Инструкции** — просмотр и управление рабочими инструкциями.
- **Пользователи** — управление учётными записями сотрудников.
- **Результаты тестов** — просмотр истории попыток и результатов обучения с фильтрами по сотруднику и должности.

## Работа с должностями

Руководитель может открыть список должностей, добавить новую, изменить название или удалить ненужную должность после подтверждения.

При удалении должности учитываются связанные с ней процессы.

## Работа с инструкциями

Инструкции организованы по должностям. Руководитель выбирает должность и получает список относящихся к ней материалов.

В основе инструкции лежит структурированное описание процесса — Process JSON.

## Контроль обучения

В разделе результатов тестирования доступна история попыток сотрудников. Можно просматривать результаты и использовать фильтры по сотруднику и должности.
