# Orto-N-L-M — MVP Status

**Дата фиксации:** 20 августа 2026

## Подтверждённый результат

Сквозной автоматический цикл Orto-N-L-M успешно пройден без ошибок.

Проверенный сценарий:

```text
Telegram
  ↓
Interview Agent
  ↓
Process JSON
  ↓
PostgreSQL
  ↓
Instruction Generator
  ↓
HTML / файл
  ↓
Telegram
```

### Что подтверждено

- Telegram-интервью запускается и завершается корректно.
- Ответ эксперта преобразуется в структурированный Process JSON.
- Process JSON сохраняется в PostgreSQL.
- Материалы интервью, включая скриншоты, сохраняются отдельно.
- На основе Process JSON формируется обучающий материал.
- HTML формируется без ошибок.
- Итоговый файл успешно создаётся.
- Готовый файл успешно отправляется пользователю в Telegram.

## Текущий DEV-режим интервью

Для ускорения автоматических тестов используется сокращённый сценарий:

- один содержательный вопрос после выбора процесса;
- максимум один запрос скриншота;
- после получения необходимых данных интервью завершается.

Это тестовый режим. Архитектура Process JSON и основной конвейер при этом сохраняются.

## Архитектурный принцип

**Process JSON является каноническим источником знаний.**

Материалы и форматы представления генерируются отдельно от канонических данных.

## Следующий этап

После подтверждения сквозного MVP-цикла — возврат к полноценному интервью, дополнительная проверка сценариев со скриншотами и дальнейшее развитие базы знаний и AI Assistant.
