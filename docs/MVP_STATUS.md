# Orto-N-L-M — MVP Status

**Актуальная фиксация:** 4 сентября 2026

## Подтверждённый рабочий результат

Система прошла сквозные проверки основных пользовательских контуров.

### Специалист

- запуск и завершение интервью;
- адаптивное интервью до 15 содержательных вопросов;
- запрос необходимых скриншотов/фото;
- голосовые ответы и транскрибация;
- формирование Process JSON;
- сохранение процесса и должности;
- генерация и отправка HTML-инструкции;
- персональный список `📂 Мои процессы`.

### Руководитель

- меню только `👤 Должности` и `📚 Инструкции`;
- список, добавление, редактирование и удаление должностей;
- подтверждение удаления;
- удаление связанных процессов перед удалением должности;
- список инструкций по выбранной должности;
- выдача инструкции без участия AI.

### Стажёр

- выбор должности;
- получение инструкции;
- генерация теста по Process JSON;
- 4 варианта ответа;
- механическая проверка;
- сохранение состояния теста;
- перемешивание вариантов при сохранении правильного ответа;
- итоговый HTML-файл и отправка в Telegram.

## Архитектурный принцип

**Process JSON является каноническим источником знаний.**

Инструкция и тест строятся только на его основании. Вложения привязываются к конкретным шагам и используются при формировании инструкции.

## Актуальная версия workflow

`Orto-N Learning Manager (33).json` — активный экспорт, 75 узлов.

## Важно

В рабочем workflow есть HTTP Request узлы с Telegram Bot API URL, содержащими токен бота. Рабочий экспорт нельзя бездумно публиковать в публичном GitHub. Поэтому репозиторий содержит актуальную документацию и контракт проекта, а секретные значения остаются в рабочем окружении n8n.

## Следующий этап

Продолжать развитие контура обучения и базы знаний, не меняя уже подтверждённое рабочее ядро без объективной причины.
