# Ортона-AI — описание проекта

## Идея

Ортона-AI — AI-платформа, которая помогает компаниям собирать практические знания опытных сотрудников, превращать их в структурированные процессы и использовать для создания инструкций и обучения новых специалистов.

## Проблема

Значительная часть рабочих знаний существует в опыте конкретных сотрудников. Когда знания не описаны и не структурированы, компания зависит от отдельных людей, а обучение новичков требует времени опытных коллег.

## Решение

Платформа проводит специалиста через AI-интервью, уточняет детали выполнения работы и формирует структурированное описание процесса — Process JSON.

На основе этого описания создаются рабочие инструкции и тесты для обучения сотрудников.

## Пользовательские роли

- **Руководитель:** управляет должностями и пользователями, работает с инструкциями, отслеживает результаты обучения.
- **Специалист:** передаёт практический опыт через AI-интервью, формирует процессы и инструкции.
- **Стажёр:** изучает инструкции, проходит тестирование и отслеживает собственный прогресс.

## Основной сценарий

```text
Эксперт → AI-интервью → Process JSON
                              ├── Инструкция
                              └── Обучение → Тест → Результат
```

Process JSON — единая структурированная основа процесса. Инструкции и тесты создаются на его основе.

## Реализованные возможности

- Веб-приложение с ролевыми кабинетами.
- AI-интервью с уточняющими вопросами.
- Текстовый и голосовой ввод.
- Обработка иллюстративных материалов.
- Формирование и сохранение Process JSON.
- Генерация инструкций.
- Обучение и тестирование сотрудников.
- Сохранение прогресса и результатов.
- Управление пользователями, должностями и доступом.

Основные пользовательские сценарии проверены в работающем production-приложении.

## Технологии

- Frontend: React 19, Vite, JavaScript.
- Backend: Python, FastAPI.
- Данные: PostgreSQL.
- AI и автоматизация: OpenAI API, n8n.
- Развёртывание: Docker, Ubuntu Server, Caddy.

## Текущие границы

Полноценная корпоративная база знаний и RAG-поиск относятся к следующему этапу развития. Для них требуется подготовленный и подключённый источник корпоративных документов.

## Назначение репозитория
