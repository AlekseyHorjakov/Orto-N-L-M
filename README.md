# Orto-N-L-M

> AI-система для обучения сотрудников и формирования базы знаний компании.

## О проекте

Orto-N-L-M собирает знания сотрудников через интервью и превращает их в структурированную базу знаний, на основе которой можно автоматически создавать обучающие материалы.

Проект разрабатывается как универсальная система, которую можно применять в разных компаниях.

## Как это работает

Сотрудник проходит интервью через Telegram. Полученная информация обрабатывается AI и сохраняется в структурированном виде — **Process JSON**.

Process JSON является каноническим источником знаний проекта. На его основе формируются производные материалы:

- инструкции;
- учебные материалы;
- тесты;
- статьи базы знаний;
- AI-помощник.

## Архитектура

```text
Telegram
    ↓
Input Gateway
    ↓
Interview Session Router
    ↓
Interview Agent
    ↓
Process JSON
    ↓
PostgreSQL
    ↓
Knowledge Generator
    ↓
Instruction / Learning Material
    ↓
File
    ↓
Telegram
```

## Основной принцип

**Process JSON — единственный источник истины.**

AI используется для обработки и генерации материалов, но знания хранятся отдельно от их представления. Это позволяет из одного набора структурированных знаний создавать разные форматы материалов без дублирования исходной информации.

## Архитектурные принципы

- один компонент — одна ответственность;
- бизнес-логика отделена от транспорта;
- Telegram используется как транспортный интерфейс;
- структурированные данные отделены от сгенерированных материалов;
- workflow отвечает за маршрутизацию и интеграцию компонентов;
- проект развивается от рабочего MVP к расширенной системе.
