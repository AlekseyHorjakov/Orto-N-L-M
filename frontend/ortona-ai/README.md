# Ортона-AI — веб-приложение

Frontend платформы Ортона-AI. Интерфейс реализован на React 19 и Vite.

## Возможности интерфейса

- Кабинет руководителя.
- Кабинет специалиста с AI-интервью.
- Кабинет стажёра для изучения инструкций и тестирования.
- Работа с должностями, пользователями и результатами обучения.

## Локальный запуск

```bash
npm install
npm run dev
```

## Production-сборка

```bash
npm run build
npm run preview
```

Для работы с данными и AI-сценариями необходим backend и настроенное окружение приложения.
